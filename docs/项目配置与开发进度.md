更新时间：2026-07-14

> 本文件是当前项目的统一查阅入口。若旧文档与本文件冲突，以本文件和 `Crane_rtos.ioc` 为准。

## 一、项目目标

项目面向物流技术创意赛散料货物搬运任务，目标是制作一台能够自主识别、规划路径、抓取并运输豆子的起重式移动机器人。

系统由移动底盘、起重机架、夹爪、K230视觉识别、STM32控制、OLED显示和调试串口组成。

## 三、直流电机最终引脚

本项目采用L298N的IN1/IN2双PWM方式，EN端只负责使能并保持高电平。

| 电机 | IN1 PWM | IN2 PWM | 定时器 |
| --- | --- | --- | --- |
| M1 | PA6 / TIM3_CH1 | PA7 / TIM3_CH2 | TIM3 |
| M2 | PB0 / TIM3_CH3 | PB1 / TIM3_CH4 | TIM3 |
| M3 | PC6 / TIM8_CH1 | PC7 / TIM8_CH2 | TIM8 |
| M4 | PC8 / TIM8_CH3 | PC9 / TIM8_CH4 | TIM8 |

控制逻辑：

```text
正转：IN1=PWM，IN2=0
反转：IN1=0，IN2=PWM
停止：IN1=0，IN2=0
```

PC0~PC4是旧方向GPIO，目前只作为预留引脚，不接L298N；PC5 已改作 Z 轴下端光电限位：

```text
PC0/PC1：M1预留
PC2/PC3：M2预留
PC4：M3预留
PC5：LIMIT_Z_MIN
```

TIM3和TIM8均为：

```text
PSC=71
ARR=99
PWM=10kHz
命令范围=0~99
```

### 电机接线

以M1为例：

```text
PA6 -> L298N IN1
PA7 -> L298N IN2
EN1 -> 5V或跳帽
电机红线 -> OUT1
电机白线 -> OUT2
```

24V电池不能直接接12V电机，应使用24V转12V降压模块给L298N电机电源供电。STM32、L298N和编码器必须共地。

## 四、编码器

| 电机 | A相 | B相 |
| --- | --- | --- |
| M1 | PD10 / ENC_M1_A | PD4 / ENC_M1_B |
| M2 | PD13 / ENC_M2_A | PD5 / ENC_M2_B |
| M3 | PD14 / ENC_M3_A | PD6 / ENC_M3_B |
| M4 | PD15 / ENC_M4_A | PD7 / ENC_M4_B |

编码器接线：黑线接GND，蓝线接3.3V，黄线为A相，绿线为B相。

当前方式为A相上升沿EXTI计数，读取B相判断方向，10ms周期计算RPM并进行一阶滤波。

当前暂定参数：

```text
encoder_counts_per_output_rev=374
speed_filter_alpha=0.35
motor_control_period_ms=10
```

资料只明确电机轴每圈11个信号，374是按约34:1减速比得到的暂定输出轴计数。正式闭环前必须手动转动输出轴一圈校准。

## 五、步进电机与TB6600

| 轴 | PUL | DIR | ENA |
| --- | --- | --- | --- |
| X轴 | PE9 / TIM1_CH1 | PD2 | PD11 |
| Z轴 | PE11 / TIM1_CH2 | PD3 | PD12 |

TB6600的ENA低电平有效，PUL上升沿走一步。Z轴已完成实机调试：细分4、800脉冲/圈、TIM1 PSC=71、ARR=499、脉冲频率2kHz。步进配置和代码保留，当前按键主要用于直流电机测试。

## 六、舵机

| 舵机 | 信号 | 定时器 |
| --- | --- | --- |
| 舵机1 | PA0 | TIM2_CH1 |
| 舵机2 | PA1 | TIM2_CH2 |

TIM2为50Hz、20ms周期。270度舵机当前角度范围0~270度，默认映射：0度=1000us、90度约1333us、270度=2000us。舵机必须使用独立5V/6V电源并与STM32共地。

舵机1当前逻辑：上电90度，K0短按减少20度，K1短按增加20度。K230串口也支持角度和脉宽设置。

## 七、K230与USART2

```text
PA2 -> USART2_TX -> K230 RX
PA3 -> USART2_RX -> K230 TX
```

串口为115200、8N1、无流控，DMA1_Channel6接收，DMA1_Channel7发送，使用DMA空闲线接收。

当前调试命令：

```text
PING
GET
S1 1500 / S2 1500
A1 90 / A2 90
AUTO START
AUTO ABORT
```

## 八、按键、OLED和任务

按键为下降沿中断、内部上拉，按下为低电平：

```text
K0：PE4 / EXTI4
K1：PE3 / EXTI3
急停：PE7 / EXTI9_5
限位：PE0、PE1、PE2、PC5
```

OLED页面顺序：总览、步进、减速电机、闭环控制、编码器、系统。K1长按切换页面。

FreeRTOS任务：

| 任务 | 函数 | 优先级 | 栈 |
| --- | --- | ---: | ---: |
| APP_CTRL | StartAppCtrlTask | 24 | 256 |
| DC_MOTOR | StartDcMotorTask | 32 | 256 |
| STEPPER | StartStepperTask | 32 | 256 |
| K230_RX | StartK230RxTask | 24 | 256 |
| INPUT_EVT | StartInputEvtTask | 32 | 256 |
| OLED | StartOledTask | 8 | 256 |

FreeRTOS堆大小为12288字节。

## 九、直流电机调试逻辑

普通“减速电机”页面：

```text
K0短按：PWM档位 0 -> 10 -> ... -> 90 -> 99 -> 0
K1短按：切换方向，换向先降到0
K1长按：切换页面
```

“闭环控制”页面：

```text
K0短按：目标RPM增加10
K1短按：目标RPM减少10
K1长按：切换页面
```

闭环页面显示目标RPM、实际RPM、PWM、编码器计数、Kp、Ki、前馈和同步参数。当前是单电机PI控速，暂未加入D项。

当前参数位于 `Core/Src/app_config.c`：

```text
Kp=0.80
Ki=2.50
前馈=0.65
滤波系数=0.35
PWM死区=8
最高目标转速=130RPM
```

推荐调试顺序：先校准编码器每圈计数；再记录开环PWM与稳定RPM；将Ki设为0，从小Kp开始增加；无明显振荡后逐步增加Ki；最后调整前馈和死区。

## 十三、比赛控制软件框架

从 2026-07-14 起，业务代码按模块拆分，`main.c` 仅保留 CubeMX 初始化、模块初始化、HAL 回调转发和 FreeRTOS 任务入口。

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 舵机控制 | `servo_control.c/.h` | 两路舵机角度/脉宽与限幅 |
| 步进轴 | `stepper_axis.c/.h` | X/Z 轴使能、方向、停止和遥测 |
| 底盘运动 | `chassis_motion.c/.h` | 手动电机调试、PI 调速、路线段执行接口 |
| 输入与安全 | `input_manager.c/.h`、`safety_manager.c/.h` | 按键消抖、急停、限位事件和故障停机 |
| K230 通信 | `k230_link.c/.h` | USART2 DMA、调试命令、后续视觉结果协议 |
| 路线表 | `robot_routes.c/.h` | 取货、绕障、放料、归位路线参数 |
| 比赛状态机 | `robot_controller.c/.h` | 自检、视觉扫描、取料、运输、放料、归位、故障 |

自动任务状态为：

```text
IDLE -> SELF_CHECK -> VISION_SCAN -> TASK_BUILD -> MOVE_TO_PICK
-> PICK_ACTION -> LIFT_SAFE -> FOLLOW_ROUTE -> DROP_ACTION
-> RETURN_FINISH -> FINISHED
```

当前自动状态机默认不会越过 `VISION_SCAN`，直到 K230 多帧确认、路线到位检测和机构动作确认全部接入，因此不会在未完成接线时误启动机械动作。

### 对射光电限位预留

| 位置 | 引脚 | 状态 |
| --- | --- | --- |
| X 轴最小端 | PE0 / `LIMIT_X_MIN` | 已有 |
| X 轴最大端 | PE1 / `LIMIT_X_MAX` | 已有 |
| Z 轴上端 | PE2 / `LIMIT_Z_MAX` | 已有 |
| Z 轴下端 | PC5 / `LIMIT_Z_MIN` | 已生成并加入 EXTI9_5 转发 |

当前选用的对射光电模块为无遮挡 `DO=低电平`、遮挡 `DO=高电平`，四路输入均采用高有效、内部下拉、上升沿 EXTI。模块 `DO` 可直连 STM32 输入的前提是模块供电为 3.3V，或已确认 `DO` 高电平不超过 3.3V；绝不可把 5V/12V/24V 高电平直接接入 MCU。
