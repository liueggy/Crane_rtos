## 当前建议调试顺序

1. 用万用表确认光电模块在遮挡时 DO 为不高于 3.3V 的高电平。
2. 单独接 Z 下端 `PC5`，检查遮挡时是否立即停止步进轴并出现故障标志。
3. 完成 Z 轴双次回零：快速找点、退离、低速二次靠近、坐标置零。
4. 校准 M1 至 M4 编码器输出轴每圈计数和轮子正反极性。
5. 实现底盘直行、原地转向、路线段到点，并以地标或磁导航校正位置。
6. 完成料斗/夹爪的取料、锁料、倾倒、复位动作。
7. 对接 K230 豆子和数字识别协议，再逐状态联调自动搬运。
